Lusitile Cerâmica

Projeto académico de desenvolvimento Front-End para uma empresa fictícia do setor da cerâmica.

O objetivo do projeto foi desenvolver um website institucional responsivo, aplicando conhecimentos de HTML, CSS e JavaScript.

Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

Funcionalidades

- Website responsivo para desktop, tablet e mobile
- Menu de navegação entre páginas
- Página inicial institucional
- Página Sobre
- Página de Produtos
- Galerias de produtos
- Efeito flip nos cartões de produtos
- Página de Contactos com formulário
- Banner de cookies
- Política de Privacidade
- Política de Cookies
- Footer responsivo

Estrutura do projeto

O website é composto pelas seguintes páginas:

- "index.html" - Página inicial
- "sobre.html" - Sobre a empresa
- "produtos.html" - Produtos e galerias
- "contatos.html" - Contactos
- "privacidade.html" - Política de Privacidade
- "cookies.html" - Política de Cookies

O projeto utiliza ainda:

- "style.css" - Estilos e responsividade
- "script.js" - Funcionalidades JavaScript
- "imagens/" - Imagens utilizadas no website

Projeto

Este projeto foi desenvolvido no âmbito da minha formação em Front-End Development, com o objetivo de consolidar conhecimentos de estruturação HTML, estilização CSS, responsividade e interação com JavaScript.
